# Касса — телефоны и чехлы

Офлайн-касса для магазина на Electron (Windows). Данные лежат файлом
`Документы/Касса/касса.json`, копии — рядом, в папке «Копии».

## Посмотреть без установки

Откройте `src/kassa.html` в Chrome или Edge. Это демо-режим с придуманным
магазином, данные хранятся в браузере. Страница `?role=owner` открывается
владельцем, `?role=cashier` — кассиром.

## Получить Касса.exe

Сборка идёт на GitHub: вкладка **Actions → «Сборка Касса.exe» → последний
запуск → Artifacts → Kassa-exe**. Внутри:

- `Касса.exe` — портативная версия, запускается двойным щелчком;
- `Kassa-Setup-1.0.0.exe` — установщик с ярлыками.

Вручную на Windows: `cd src && npm install && npm run dist`
(результат в `dist-exe/`).

## Ключ программы

Касса открывается ключом, привязанным к компьютеру. Клиент диктует «код этого
компьютера», вы получаете ключ командой:

    node tools/выдать-ключ.js A1B2-C3D4-E5F6

## Тесты

    cd src && npm install && npx playwright install chromium && npm test
