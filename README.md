# Касса — телефоны и чехлы

Офлайн-касса для магазина на Electron (Windows). Данные лежат файлом
`Документы/Касса/касса.json`, копии — рядом, в папке «Копии».

## Посмотреть без установки

Откройте `src/kassa.html` в Chrome или Edge. Это демо-режим с придуманным
магазином, данные хранятся в браузере. Страница `?role=owner` открывается
владельцем, `?role=cashier` — кассиром.

## Получить Касса.exe

Сборка идёт на GitHub: вкладка **Actions → «Сборка Касса.exe» → последний
запуск → Artifacts → Kassa-exe**. Внутри:

- `Касса.exe` — портативная версия, запускается двойным щелчком;
- `Kassa-Setup-1.0.0.exe` — установщик с ярлыками.

Вручную на Windows: `cd src && npm install && npm run dist`
(результат в `dist-exe/`).

## Ключ программы

Касса открывается ключом, привязанным к компьютеру. Клиент диктует «код этого
компьютера», вы получаете ключ командой:

    node tools/выдать-ключ.js A1B2-C3D4-E5F6

## Код владельца и его сброс

Код владельца (четыре цифры) в файле данных хранится не открытым текстом, а
хешем с солью. После пяти неверных попыток подряд вход блокируется на минуту,
дальше ожидание удваивается, до 15 минут. Блокировка сохраняется при
перезапуске.

Если владелец забыл код: в кассе «Войти как владелец» → «Забыли код?». Касса
покажет код компьютера; владелец диктует его вам, а вы выдаёте код сброса:

    node tools/выдать-ключ.js КОД_КОМПЬЮТЕРА

В ответе строка «Сброс PIN». Код сброса подходит только этому компьютеру и не
затрагивает данные магазина. Запасного кода, который открывал бы любую кассу,
больше нет.

Важно: код защищает вход в программу, а не сам файл. Данные лежат в
`Документы/Касса/касса.json` в читаемом виде, поэтому кассиру лучше работать
под отдельной учётной записью Windows без доступа к папке владельца.
